### What we do

| | |
|---|---|
| **AI products** | Image, video and voice pipelines, assistants, content tools |
| **Web apps** | Landing pages, dashboards, payments and integrations |
| **Bots** | Telegram bots for bookings, support and verification |
| **Automation** | Scripts and workflows that replace repetitive manual work |

### How we work

- **Small scope first.** A working version early, then improvements based on real use.
- **Tested by running.** Work counts as done only after it has been run and checked.
- **Honest AI.** AI-generated content is labeled as AI.
- **Privacy by default.** Secrets stay out of code and out of chat.
